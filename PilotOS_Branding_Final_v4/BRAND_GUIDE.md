# PilotOS — Branding final

## Identidad

**PilotOS by NexOS**  
**Claim:** Gestión inteligente para flotas.

PilotOS se posiciona como sistema operativo para la gestión operativa, económica y documental de flotas: partes diarios, gastos, documentos, mantenimientos, avisos, informes y control de un vistazo.

## Logo seleccionado

Esta carpeta usa como referencia visual directa el branding board aportado por Alberto. La versión principal está en:

- `00_referencia/branding_board_referencia_original.png`
- `01_logo/png_reference/pilotos_logo_vertical_referencia_4k_fondo_oscuro.png`
- `01_logo/png_transparent/pilotos_logo_vertical_referencia_4k_transparente.png`

También se incluye una reconstrucción vectorial limpia en `01_logo/svg_vector_rebuild/`. Es útil como base editable, pero la referencia estética principal sigue siendo el board original.

## Paleta

- Pilot Yellow: `#FFB703`
- White: `#FFFFFF`
- Black: `#05070B`
- Panel Dark: `#171717`
- Control Gray: `#6B6B6B`
- Line Gray: `#2A2A2A`

## Tipografía

Recomendada: **Montserrat**.  
Alternativas: Poppins, Inter, Arial, sans-serif.

No se incluyen archivos de fuente dentro del pack.

## Uso visual

- Fondo principal oscuro.
- Amarillo solo como acento de control, OS, iconos y llamadas a la acción.
- Estética tecnológica, operativa y premium.
- Evitar sobrecargar con iconografía de taxi: el enfoque es flotas.

## Mensajes principales

- Gestión inteligente para flotas.
- Control total de un vistazo.
- Avisos automáticos y mantenimientos.
- Documentos y gastos siempre organizados.
- Métricas que impulsan tu negocio.

## Ecosistema

PilotOS forma parte del ecosistema NexOS y se apoya en GlorIA como agente conversacional visible.

## Estructura del pack

- `00_referencia/`: imagen original de referencia y recortes.
- `01_logo/`: logos, isotipo, favicons y vector reconstruido.
- `02_colores_tipografia/`: paleta, tokens CSS y snippet Tailwind.
- `03_redes/`: post, story y banner LinkedIn.
- `04_web_dashboard/`: mockups para landing y dashboard.
- `05_documentos_comerciales/`: tarjeta y firma de email.
- `06_print_shop/`: instrucciones para imprenta/rotulación.
- `07_prompts/`: prompts para generar nuevas piezas manteniendo la línea.
